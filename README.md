# 💜 FinTrack

**FinTrack** adalah aplikasi manajemen keuangan pribadi berbasis web yang dirancang untuk membantu pengguna memantau pemasukan, pengeluaran, dan target tabungan secara terorganisir.

---

## 📋 Fitur Utama

| Fitur | Keterangan |
|-------|-----------|
| 🔐 Autentikasi | Login/Register dengan Email + Google OAuth |
| 🐷 Celengan | Buat target tabungan dengan estimasi otomatis |
| 📋 To Do List | Catat tagihan dan pengeluaran rutin |
| 📊 Laporan Keuangan | Rekap pemasukan & pengeluaran |
| 📄 Ekspor PDF/CSV | Cetak laporan keuangan profesional |
| 📧 Notifikasi Email | Kirim notifikasi transaksi via EmailJS |

---

## 🛠️ Teknologi yang Digunakan

- **HTML5, CSS3, JavaScript (ES6)** - Frontend
- **Firebase** - Authentication & Firestore Database
- **jsPDF** - Ekspor PDF
- **EmailJS** - Notifikasi email
